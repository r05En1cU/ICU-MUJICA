# ICU-MUJICA v2.0.0 Phase 1 Brainstorm 3 Architecture

> 日期：2026-06-06
> 主题：尝试建模 ICU-MUJICA 的生成和反馈流程，提供数学 or 系统底层思考

## 本轮记录方式

本文件用于记录 ICU-MUJICA v2.0.0 phase 1 architecture brainstorming 的原始想法、筛选判断和阶段性结论。

记录时区分三类内容：

```text
Raw Idea      原始想法，尽量保留提出时的语义
Filter Note   筛选意见，判断是否进入 phase 1 架构核心
Summary       收束结论，沉淀为后续设计或实现依据
```

筛选标准暂定如下：

- 是否服务于 phase 1 最小闭环；
- 是否强化 Harness / SkillGraph / RAG & Memory 的边界；
- 是否能被 trace、tool feedback 或用户反馈验证；
- 是否避免过早引入完整动态 graph learning；
- 是否能控制 skill、workflow、memory 的复杂度增长。

## 已有架构共识

### 系统定位

ICU-MUJICA v2 当前不再沿用 v1 的多 Docker、多 Agent 路线，而是收束为：

```text
Single LLM
+ Harness
+ Multi-skill Runtime
+ Explicit Workflow
+ Layered Memory
+ IC / HDL Tool Feedback
```

因此，它更接近面向 IC / HDL 设计流程的可进化 multi-skill 自动化系统，而不是通用 coding agent 或多 agent 人格协作系统。

### 稳定核心与可变层

稳定核心主要包括：

```text
Harness Runtime
Planning Runtime
Skill Runtime
Evaluation Runtime
Memory Runtime
Artifact / Trace Runtime
Tool / Linter Runtime
```

可变层主要包括：

```text
Skill Definitions
Skill Prompts
Evaluator Criteria
Workflow Templates
Routing Policies
Memory Entries
RAG Ranking
Graph Memory Edges
Linter Rule Sets
```

phase 1 的关键不是让核心 runtime 自动重写自己，而是让 skill、workflow、routing、memory 和 evaluator 可以在受控复杂度下被记录、调整、验证和回滚。

### Agent 主链

Agent 主链暂定为：

```text
Agent Chain
|- Harness
|- SkillGraph
|- RAG & Memory
```

其中：

- Harness 是稳定运行核心，负责 session、workspace、artifact、trace、tool 调用、异常恢复和用户反馈记录；
- SkillGraph 是能力与流程层，负责 skill node、composite skill、workflow template、routing policy 和 evaluate / execute / verify 生命周期；
- RAG & Memory 是经验与上下文层，负责历史项目、失败模式、用户反馈、graph memory 与检索上下文。

### Phase 1 最小闭环

phase 1 最重要的验证闭环暂定为：

```text
User Spec
 -> Harness 创建 session
 -> Workspace / project md 记录中短期上下文
 -> Planning 选择一个固定 workflow
 -> Skill Runtime 加载 skill definition
 -> Evaluator 定位问题或生成检查建议
 -> Executor 生成 RTL / patch / testbench / script
 -> Verifier / Linter / Tool 进行验证
 -> Artifact Runtime 保存结果与 trace
 -> Memory Runtime 记录失败模式、修复方式和触发条件
 -> 后续同类任务自动触发相关 evaluator / routing
```

当前最重要的收束点是：

```text
先证明经验能改变后续 workflow，而不是先实现完整自进化框架。
```
